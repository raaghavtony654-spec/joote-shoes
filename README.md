# Joote — Handcrafted Indian Sneakers 👟🇮🇳

> **Built Different. Walk Different.**  
> Authentic Indian craft traditions meets modern streetwear silhouettes.

---

## 🌟 Overview

**Joote** celebrates India's rich textile heritage by bringing centuries-old artisanal techniques—Kantha, Zari, Kasuti, and Chikankari—into modern handcrafted sneakers. Every pair tells a story of tradition, patience, and meticulous skill.

---

## ✨ Features

- **Interactive 3D-Feel Banner Showcase**: Dynamic radial backgrounds, rotating dial animations, and particle effects.
- **Cinematic Shimmer Loading Screen**: Signature cursive brand entrance with metallic gold shimmer and seamless FLIP docking.
- **Craft-Centric Catalog**: Dedicated showcase for Kantha, Zari, Kasuti, and Chikankari craftsmanship.
- **Full Shop Grid**: Detailed product cards with pricing, status badges, and direct checkout links.
- **Responsive & Seamless Navigation**: Pill-bar sticky navigation, dynamic scroll shrinking, and staggered grid transitions.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**: High-performance animations, fluid typography, and custom design tokens.
- **Vanilla JavaScript**: Lightweight state management, particle engine, and FLIP animations.
- **Typography**: Google Fonts (*Dancing Script*, *Unbounded*, *Cinzel*, *Montserrat*, *Poppins*).

---

## 🚀 Running Locally

You can run the project using any local HTTP server:

```bash
# Using serve
npx serve . -l 3456

# Using Python
python -m http.server 3456
```

Then open [http://localhost:3456](http://localhost:3456) in your browser.

## 📜 Heritage Crafts Featured

| Craft | Origin | Technique |
| :--- | :--- | :--- |
| **Kantha** | Bengal, East India | Intricate running stitch patterns creating rich tactile textures. |
| **Zari** | Surat & Varanasi | Fine gold and silver metallic threads woven into textiles. |
| **Kasuti** | Karnataka, South India | Geometric patterns embroidered without tracing for extreme precision. |
| **Chikankari** | Lucknow, Uttar Pradesh | Artful, delicate hand embroidery on upper canvas panels. |
